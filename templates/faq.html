Explain more

The idea is every big, scary, packing list is made up of several high level activities like "staying overnight" or "car trip". These activities are easier to think of and can be reused across multiple trips. For example, to visit a friend for the weekend you might select "staying overnight", "hiking" and "car trip". Organiser combines these lists, removes duplicates and applies any special rules you've defined.

Advanced Logic

You can add special rules for how lists are combined. Everything is done via text, like an old forum markup system:

Syntax Meaning
Socks Required item
Socks? Optional — dropped if Socks is also present
-Socks Remove Socks / Socks? from the result
~List Include all the items of an activity called "List" (recursive)
~List? Same, but every included item becomes optional
-~List Remove that activity’s items from the result
Socks!! Keep even if -Socks is present (!! stripped in output)

Exact duplicates are removed. Missing ~ references are left as-is.
